# LIQRA 開発引き継ぎ

LIQRAは、訪れた場所や体験を写真付きで記録し、ボードや地図で振り返るiOS・Android向けアプリです。Expo / React Native / TypeScriptで開発しています。

- 記録は初期設定で非公開。訪問日・メモ・写真（最大10枚）・代表写真を設定でき、同じ場所を含む複数ボードに1件の記録を反映できます。反映先はボードごとに外せます。
- 初期のマイボードは47都道府県。地方別などの公式テンプレートはSupabaseから配信し、Web管理画面で編集・公開できます。追加済みボードの更新時も、既存の記録を保持します。
- Apple・Google・LINEのログインを実装。ゲストは「みんな」の公開記録を閲覧できます。ボード編集や記録にはログインが必要です。
- ボード・記録・写真はクラウド保存。別のiOSシミュレーターで同じLINEアカウントにログインし、記録と写真の復元を確認済みです。
- 「みんな」に公開前プレビュー、いいね、取り下げ、通報・ブロックを実装済み。記録詳細から公開前の確認画面に進めます。通報・ブロックのDB設定も反映済みです。

直近のiOSシミュレーター確認では、写真選択・代表写真・カレンダー・ボード別チェック・既存記録の保存・プロフィール検索・公開前プレビューまで動作しました。既存の記録は非公開のままです。

次の確認は、利用者が公開してよいと選んだ記録での「公開 → 別アカウントから閲覧・いいね → 本人による取り下げ」です。取り下げ後も元の写真とボード達成が残ることを確認します。実際の公開投稿を使った一連の操作は未検証です。普段の開発確認はシミュレーターで行い、実機テストは最後に行います。
